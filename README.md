# Levi's Homebrew Tap

Personal Homebrew tap for apps and tools.

## Available Casks

- **mark-this-down** — Native macOS markdown editor. [Source](https://github.com/LeviHirsch/mark-this-down).

## Usage

```sh
brew tap LeviHirsch/tap
brew install --cask mark-this-down
```

To upgrade later:
```sh
brew upgrade --cask mark-this-down
```
